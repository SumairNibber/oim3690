javascript image processing
1. images are grids of pixels
2. each pixel stores RGBA values
    red
    green
    blue
    alpha
3. canvas lets JavaScript draw an image and read its pixel data
4. pixel data is stored in one long array
5. loop through image data 4 values at a time because each pixel has 4 channels
6. filter ideas from class
    red filter keeps red and removes green and blue
    grayscale averages red, green, and blue
    negative subtracts each color value from 255
7. image processing practice used arrays, loops, index math, functions, and the DOM together
