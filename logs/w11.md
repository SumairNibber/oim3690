apis and fetch
1. an API is a way for programs to talk to each other and usually send data as JSON
2. JSON looks like JavaScript objects but is just a text format for data
3. fetch() sends a request to a URL and returns a response
4. await pauses until the network request finishes
5. async marks a function that can use await
6. try/catch helps handle network errors or bad responses
