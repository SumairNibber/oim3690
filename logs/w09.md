javascript basics
1. variables
    use let for values that change
    use const for values that stay the same
    avoid var
2. naming rules
    start with a letter, _ , or $
    no spaces or special characters
    camelCase for variables and UPPER_CASE for constants
3. data types
    string
    number
    boolean
    undefined
    null
4. typeof helps check the type of a value
5. template literals use backticks and ${} to build strings more easily
6. operators
    arithmetic operators like + - * / % **
    comparison operators
    logical operators
7. functions
    functions group reusable steps
    parameters let functions take inputs
    return sends a value back
    arrow functions are a shorter syntax I will see often in AI-generated code
8. functions can be used as event handlers with addEventListener
9. objects
    objects group related data together
    properties are accessed with dot notation
    methods are functions stored inside objects
