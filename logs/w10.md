javascript functions and conditionals
1. functions group reusable steps and can take parameters and return values
2. arrow functions are a shorter syntax I will see often in JavaScript and AI-generated code
3. conditionals let code make decisions with if, else if, and else
4. comparison operators
    use === and !== for strict checks
    use >, <, >=, and <= for ranges
5. logical operators
    && means both conditions must be true
    || means at least one can be true
    ! reverses a condition
6. truthy and falsy values affect whether an if statement runs
7. grade calculator practice
    write a getGrade(score) function
    validate empty input and scores outside 0 to 100
    only show a grade when the input is valid
