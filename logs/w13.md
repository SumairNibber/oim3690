beyond frontend and deployment
1. frontend is the part users see in the browser, while backend runs on a server and handles logic, data, and authentication
2. APIs act as the bridge between frontend and backend
3. common HTTP methods
    GET reads data
    POST creates data
    PUT updates data
    DELETE removes data
4. databases solve problems that localStorage cannot, like shared data, larger storage, and multi-user apps
5. SQL databases use structured tables, while NoSQL databases store more flexible document-style data
6. Node.js is a natural backend step because it uses JavaScript on the server
7. frameworks like React, Vue, Next.js, and Svelte build on the same fundamentals we learned with DOM, events, fetch, and state
8. GitHub Pages is best for static HTML, CSS, and JavaScript projects
9. Vercel or Render are better when a project needs server code or hidden API keys
10. environment variables help protect keys on the server side, but client-side code is always visible in the browser
11. custom domains are optional, and Vercel plus DNS records can connect a personal domain to a deployed project
