forms and user input
1. forms let users send data to a website
    sign up, login, search, contact forms, settings, checkout
2. form basics
    use the <form> element with action and method
    GET puts data in the URL and is good for search/filtering
    POST sends data in the request body and is better for login or sensitive info
3. important form elements
    input
    textarea
    select and option
    button
    label
4. use the right input types
    text, email, password, number, tel, url, date
    browser validation helps when you choose the right type
5. labels matter for accessibility
    label for should match the input id
    name is the key sent to the server
    labels help screen readers and make forms easier to click
6. contact form practice
    add at least name, email, and message
    style the form with CSS and try flexbox for layout

responsive design
1. one website should work across desktop, laptop, tablet, and phone
2. use the viewport meta tag so mobile browsers do not assume the page is desktop sized
3. mobile-first approach
    design for small screens first
    add more complexity for larger screens later
4. media queries let the layout change at different screen sizes
5. responsive techniques
    fluid layouts
    relative units
    responsive images
    responsive typography
    show or hide elements when needed
6. test in Chrome DevTools device mode
    check for horizontal scrolling, readable text, tappable buttons, working nav, and properly scaling images

framework preview
1. AI often writes Tailwind or framework-style CSS instead of plain CSS
2. do not memorize every class, just learn how to read what the classes are doing
